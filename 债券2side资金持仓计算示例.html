债券 2side 资金与持仓计算示例（功能点六）

本文用一组数字算例说明债券 2side 模式下的「资金口径」与「持仓可用口径」计算。 每个场景都同时给出 TRS 清算速度 = T+0 与 TRS 清算速度 = T+1 两套结果，便于对比清算速度差异带来的资金影响。 统一约定：单位面值 = 100 元，汇率 = 1，最新全价 = 104（仅用于浮动盈亏；保证金按持仓全价计），预付金见各场景。

一、概念与公式澄清

1.1 两套清算速度

名称 绑定对象 决定什么 取值
TRS 清算速度 框架主合约（整支债券/账户层） 资金口径：持仓总额、保证金占用、平仓盈亏归属（T+0/T+1）、可用资金 T+0 或 T+1
订单（现券）清算速度 每一笔下单 持仓可用口径：T+0 可用、T+1 可用，以及开/平时「可平对手仓」的匹配范围 T+0 或 T+1

优先级：资金计算以 TRS 清算速度 为准；TRS 清算速度 > 订单清算速度。 即使每笔订单是 T+1，只要 TRS = T+0，资金侧（持仓总额、平仓盈亏）就按 T+0 处理。

保证金占用同样受 TRS 影响：占用按「持仓总额」计提，而持仓总额在 TRS=T+1 下平仓不扣、并存膨胀（见 1.3），故同一组订单在 TRS=T+1 下占用更高。

1.2 三档保证金率

保证金率 取值 适用对象
历史初始保证金率 12% 期初（历史存续）仓位计算「初始保证金」
当日初始保证金率 10% 当日新开仓位计算「初始保证金」
当日维持保证金率 8% 全部持仓（历史+当日）计算「维持保证金」（按持仓全价，即建仓成本价）

初始保证金与维持保证金都按持仓全价（建仓成本价）计算，仅费率不同。因初始率（12%/10%）恒大于维持率（8%），故 保证金占用 = 初始保证金（max(初始, 维持) 恒取初始）。维持保证金仍列出以示完整。

1.3 资金口径字段与公式

设某笔持仓明细：券面总额 = E（元），建仓全价（持仓全价）= P，最新全价 = M（=104，仅用于浮动盈亏），则「合约张数」= E / 100。

字段 公式
单笔初始保证金 (E/100) × P × 初始率（历史仓 12% / 当日仓 10%）× 期初汇率
单笔维持保证金 (E/100) × P（持仓全价） × 8% × 汇率
保证金占用 Σ 持仓总额明细 max(初始, 维持)（持仓总额按 TRS 计，见下）
单笔平仓盈亏（平多） (平仓成交全价 − 建仓全价) × (平仓券面/100)
单笔平仓盈亏（平空/回补） (建仓全价 − 平仓成交全价) × (平仓券面/100)
单笔浮动盈亏（多） (M − P) × (E/100)
单笔浮动盈亏（空） (P − M) × (E/100)
浮动盈亏 Σ 持仓总额明细的单笔浮动盈亏（按 TRS 口径的持仓明细计）
可用资金 预付金 − 保证金占用 − 保证金冻结 + T+0 平仓盈亏 + 浮动盈亏

保证金冻结（开仓在途）—— 按成交/撤单顺序重算，用在途开仓订单的委托价 - 冻结只针对在途开仓部分。每当发生成交或撤单，都按当前成交顺序 / 撤单顺序对剩余在途订单重新判定开平（先平后开，平不完的部分为在途开仓）。 - 逐笔计算再求和： 保证金冻结 = Σ 各在途开仓订单 (该订单开仓券面/100) × 该订单委托全价 × 当日初始率10% × 汇率。 - 关键：在途开仓部分会因成交/撤单顺序而「换单」。 当原开仓订单成交后、由另一笔委托价不同的在途订单接替开仓角色时，冻结必须用新订单的委托价重算，而不是沿用原冻结金额（见场景一 S3：B 成交后 A 接替开空 2,000，委托价由 100 变 102 → 冻结 200 → 204）。 - 若接替订单与原订单委托价相同，则重算结果与「按数量比例」一致；开仓真正成交落地为持仓后，该部分冻结转为保证金占用。

平仓盈亏归属（关键） - TRS = T+0：所有平仓盈亏（含订单为现券 T+1 的成交）都计入 T+0 平仓盈亏 → 进入可用资金。 - TRS = T+1：所有平仓盈亏计入 T+1 平仓盈亏 → 不进入可用资金（次日清算才释放）。

持仓总额（决定保证金/浮盈的持仓口径，按 TRS 计） - TRS = T+0：持仓总额 = 期初 + 开仓成交 − 平仓成交（净头寸，平仓即扣减）。 - TRS = T+1：持仓总额 = 期初 + 开仓成交（平仓当日不扣减），同向历史+当日仓位与反向新开仓位并存膨胀，保证金与浮盈按膨胀后的全部明细计提。

1.4 持仓可用口径字段与公式（按订单/现券速度，与 TRS 无关）

每个方向（多/空）概念上分两个「簿」：期初/T+0 簿 与 T+1 簿。

单向借券规则（橙色规则，已确认） - 现券 T+0 平仓：只在 期初/T+0 簿 内匹配，不向 T+1 开仓簿借券。 - 现券 T+1 平仓：可先向 期初/T+0 簿 借券，再扣 T+1 簿。

字段 公式
T+1 可用 期初 + 现券(T+0+T+1)开仓 − 全部平仓
T+0 可用 期初 + 现券 T+0 开仓 − T+0 实扣平仓
T+0 实扣平仓 日内 T+0 平仓 + 日内 T+1 平仓 − ( 日内 T+1 开仓总量 − T+1 存活开仓量 )
T+1 存活开仓量 当日 T+1 开仓后尚未被平仓的数量

1.5 开平判定与成交顺序

  • 一笔成交（方向 D、速度 S、数量 Q）：先在「可平对手仓」中按 FIFO 平仓，平不完的部分在 S 对应的簿内开仓。
  • S = T+0：可平对手仓 = 期初/T+0 簿的反向持仓。
  • S = T+1：可平对手仓 = 期初/T+0 簿 + T+1 簿的反向持仓。
  • 开仓校验资金（冻结/占用），平仓不校验可用持仓（2side）。
  • 持仓方向、开/平、盈亏均按「成交顺序」逐笔推进；撤销或补录成交会重排成交序列，从而改变开平结果与资金（见场景五、场景六）。

二、场景一：两笔 T+1 Sell，后单先成交（订单均为现券 T+1）

2.1 TRS = T+0（主口径，分步）

阶段 事件 持仓总额(多/空) 占用 冻结 累计平仓盈亏 浮动盈亏 可用资金 T+0可用 T+1可用
S0 期初 多10,000 1,200 0 0 400 9,200 多10,000 多10,000
S1 下单A（全平，冻结0） 多10,000 1,200 0 0 400 9,200 多10,000 多10,000
S2 下单B（超卖开空2,000） 多10,000 1,200 200 0 400 9,000 多10,000 多10,000
S3 B先成交 Sell5,000@101，平多5,000（A接替为在途开仓2,000@委托102） 多5,000 600 204 50 200 9,446 多5,000 多5,000
S4 A后成交 Sell7,000@103，平多5,000+开空2,000@103 空2,000 206 0 200 −20 9,974 0 空2,000

关键算式 - S0 浮盈 = (104−100)×(10,000/100) = 400；占用 = 100×100×12% = 1,200。 - S2 冻结(B)：按下单顺序 A 先在途平 7,000 → B 可平 3,000、开空 2,000，冻结用 B 委托价 100 = (2,000/100)×100×10% = 200。 - S3 B 全成交后，按成交顺序重排剩余在途 = A：长仓只剩 5,000，A 卖 7,000 → 平 5,000 + 开空 2,000。开仓角色由 B 换成 A，委托价由 100 变 102，冻结用 A 委托价 102 重算 = (2,000/100)×102×10% = 204（不再是 200）；平仓盈亏 = (101−100)×50 = 50（入可用）；浮盈 = (104−100)×50 = 200。S3 可用 = 10,000 − 600 − 204 + 50 + 200 = 9,446。 - S4 A 成交，开空 2,000 落地为持仓 → 在途开仓归 0，冻结释放为 0、转为占用 = 20×103×10% = 206；平仓盈亏 (103−100)×50 = 150，累计 200；空头浮盈 = (103−104)×20 = −20。 - S4 可用 = 10,000 − 206 − 0 + 200 + (−20) = 9,974。

字段 TRS = T+0 TRS = T+1
持仓总额 净空 2,000 @103 多10,000 @100 + 空2,000 @103（膨胀）

8.2 三条核心区别

  1. TRS 清算速度决定资金口径（含保证金占用） - T+0：持仓总额取净头寸（平仓即扣），平仓盈亏全部进可用；占用、浮盈按净头寸计。 - T+1：持仓总额平仓不扣（同向历史/当日 + 反向新开并存膨胀），平仓盈亏不进可用；占用与浮盈均按膨胀明细计提，可用更低。

  2. 订单（现券）清算速度 + 单向借券规则决定持仓可用与开平方向 - 现券 T+0 平仓只在期初/T+0 簿匹配，不借 T+1 簿；现券 T+1 平仓可借期初/T+0 簿。 - 订单速度不一致时，T+0 簿与 T+1 簿可呈相反方向、净头寸为 0 仍双边占保证金（场景二），与 TRS 取值无关。

  3. 成交顺序决定开平与盈亏，撤销/补录会重排序列 - 开/平、方向、盈亏严格按成交顺序逐笔推进。 - 撤销先成交或中间成交、补录成交都会重排成交序列，进而改变开平结果、持仓方向与各项资金（场景五、六）。

8.3 保证金冻结与浮动盈亏要点

  • 冻结按成交/撤单顺序重算，用在途开仓订单的委托价：每次成交或撤单后，按当前顺序重判在途开平，冻结 = Σ 各在途开仓订单(开仓券面/100 × 委托全价 × 当日初始率)。若开仓角色由另一笔委托价不同的订单接替，需用新订单委托价重算（场景一 S3：B 成交后 A 接替，委托价 100→102，冻结 200→204）；开仓落地为持仓后转为保证金占用。
  • 浮动盈亏：= (最新价−建仓价)×(券面/100)×方向，计入可用资金；按 TRS 口径的持仓明细计（T+1 膨胀明细 → 浮盈也按膨胀计）。
